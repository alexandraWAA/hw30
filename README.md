# LMS Project

LMS (Learning Management System) - платформа для онлайн-обучения с REST API на Django REST Framework.

## 🚀 Технологии

- Python 3.10+
- Django 4.2.7
- Django REST Framework 3.14.0
- PostgreSQL
- Pillow (для работы с изображениями)
